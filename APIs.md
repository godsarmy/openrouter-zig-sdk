# OpenRouter API Reference

The canonical endpoint inventory is [`docs/api/coverage.md`](docs/api/coverage.md). It is the single categorized matrix of all 83 implemented client operations, including OAuth, key management, BYOK, guardrails, workspaces, organization, files, and observability.

For planned work and audited specification gaps, see [`docs/api/roadmap.md`](docs/api/roadmap.md); it does not change implemented coverage.

The base URL is `https://openrouter.ai/api/v1`; paths are relative to it. The upstream-deprecated `POST /credits/coinbase` is intentionally not implemented.

For runnable endpoint demonstrations, see [the example catalog](docs/examples/catalog.md).
