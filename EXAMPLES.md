# Examples

Runnable examples live in [`examples/`](examples/) and are registered in [`build.zig`](build.zig). Build them all with:

```sh
zig build examples
```

The canonical [example catalog](docs/examples/catalog.md) maps every `run-*` step to its source, purpose, and authentication requirement. [Advanced usage](docs/examples/advanced-usage.md) preserves guidance for concurrent I/O, Fusion, server tools, provider routing, OAuth PKCE, and integration tests.
